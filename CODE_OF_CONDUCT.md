# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in this project a harassment-free experience for
everyone.

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Accepting constructive criticism gracefully

Unacceptable behavior includes harassment, trolling, and publishing others' private
information.

## Enforcement

Report incidents to the MOTOC maintainers via GitHub Security Advisories or the
configured private contact. Maintainers will review and respond appropriately.
